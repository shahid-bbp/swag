# S For Swag Typography Assets

This directory contains self-hosted web fonts for the S For Swag luxury salon website.

## Installed Fonts
- **Crawling** (`CrawlingPersonalUsed` — Primary Display Font):
  - `CrawlingPersonalUsed.woff2` (Compressed web delivery)
  - `CrawlingPersonalUsed.otf` (Original OpenType source)
  - Preloaded in `<head>` and defined across all hero titles, H1–H3, and section headings.
- **Poppins** (Self-hosted Google Fonts WOFF2 files in `poppins/`):
  - `poppins-300.woff2` (Light)
  - `poppins-400.woff2` (Regular)
  - `poppins-500.woff2` (Medium)
  - `poppins-600.woff2` (SemiBold)
  - `poppins-700.woff2` (Bold)

## Commercial Brand Fonts
1. **Crawling** (`CrawlingPersonalUsed`):
   - Installed and operational via `CrawlingPersonalUsed.woff2` & `CrawlingPersonalUsed.otf`.
2. **CS Boris** (`CSBoris-Regular`):
   - Place licensed webfont files here (`CSBoris-Regular.woff2`, `CSBoris-Regular.ttf`) when ready.
   - Currently decorated ampersands use `font-accent` with graceful fallback.
